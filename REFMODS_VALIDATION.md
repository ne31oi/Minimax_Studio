# Проверка RefMods — 29 октября 2026

Проверено на установленной ComfyUI **0.33.0**, RTX **5060 Ti 16 ГБ**, torch **2.11.0+cu130**. Сборка ComfyUI сохранена. MiniMaxH3Mod закреплён на `517e8c419a8584fbf69fceb487bc39d83e6a6ec8`. Использованы существующие `minimax_h3_video_vae_int8_convrot.safetensors` и `minimax_h3_audio_vae_fp32.safetensors`, Qwen3-VL NVFP4 и H3 FastVideo INT8.

## Формат, графы, очередь

- **30 проверок** `scripts/test-refmods.cjs`: старый самостоятельный файл, смешанный v5, BF16-экспорт без преобразования данных, LoRA/ReFLora, повреждения, геометрия, будущая версия, sidecar, выход за папку, бюджеты/копии/нулевая сила, перенумерация меток, неизменность пустого графа, все ветви Draft/Full, ControlNet, окна Refine, Face Refine, Tile и кривые обоих проходов/плиток.
- **8 проверок** `scripts/test-refmods-python.py`: настоящий API нод закреплённого пакета и ComfyUI, один вызов кодирования промпта, однократное добавление conditioning, сохранение первого/последнего кадра, отсутствие переноса между запросами, компоненты/копии/SHA/бюджет, чтение аудио проекта вне `input/`, карта меток при исключении компонента кривой. Модельные объекты в этих CPU-проверках заменены тестовыми; реальные VAE проверены отдельно ниже.
- **5 проверок журнала** `scripts/test-refmods-jobs.cjs`: повторная отправка, потерянный ответ POST, отмена во время отправки и чтения истории, восстановление завершения, явная ошибка после потери задачи при перезапуске ComfyUI.
- Production-сборка с проверкой TypeScript проходит с предусмотренным проектом heap 8192 МБ. Лимита 6144 МБ этому проекту недостаточно.
- Браузером проверены библиотека, создание/повторное открытие проекта, загрузка исходника, конфликт `updatedAt`, редактор маски, сохранение, отдельные наборы разделов. A/B дополнительно проверяется с перехватом POST до GPU: два одинаковых seed/промпта, пустой и выбранный набор, общий ID сравнения.
- Реальный API проверен: превышение бюджета отклонено до запуска; повторный clientToken возвращает тот же prompt ID; предпросмотр и генерация завершены. Итоговый `.meta.json` содержит версию файла, бюджет 5120 и фактический `<Picture 1>`.

## Реальные VAE

Созданы и прочитаны Full Reference (100 токенов), Compressed Reference (16), смешанный комплект (420: изображение, видео, два аудио), комплект с обрезкой, масками и разными пропорциями (608). Получены PNG, MP4 и WAV предпросмотры.

В последнем комплекте геометрия компонентов сохранилась раздельно: `[1,24,1,44,28]`, `[1,24,1,20,20]`, `[1,24,2,20,20]`. Проверены маска обрезанного изображения и статическая маска видео. Для генерации с двумя персонажами выбран только первый и второй компоненты. Файл проверен по SHA перед применением.

## Что показало сравнение качества

В сравнении с seed 42319 обычный референс и Full RefMod сохраняют узнаваемый тестовый мультяшный образ. При агрессивном сжатии до сетки 8×8 с одной итерацией доработки внешность потеряна: получается другой персонаж. Это не оценка всех вариантов Compressed Reference. Исходник уже был декодирован из сжатого примера и содержит искажения. На коротком продлении с двумя шагами видны смазывание и деформации при повороте. Формат и стыковочные ноды работают, но такого прогона недостаточно для одобрения качества движения.

В отдельном тесте двух персонажей взрослый человек и мультяшный персонаж сохранены раздельно и поворачиваются друг к другу. Полное качество движения, мимики, стыков и лиц на длинных сценах ещё требует просмотра роликов с производственными настройками. Контактные полосы не заменяют такой просмотр.

Аудио проверено на кодирование, декодирование и применение в conditioning. Один из исходников — тестовый тон, другой — звук тестового видео. **Перенос личности голоса и привязка голоса к персонажу не подтверждены; субъективная оценка речи/музыки не выполнена.** Аудио остаётся экспериментальным согласно ограничениям автора пакета.

Релиз не публиковался. Перед выпуском нужны длинные сравнительные сцены на рабочих настройках, прослушивание речи и проверка высоких разрешений. Успешное выполнение перечисленных графов подтверждает техническую интеграцию, а не универсальное качество переноса.

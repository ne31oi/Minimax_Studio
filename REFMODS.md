# RefMods в MiniMax Studio

RefMods — сохранённые визуальные и экспериментальные аудиореференсы. Они хранят латенты существующих VAE; создание файла не обучает веса H3. Мастерская использует MIT-пакет [ComfyUI-MiniMaxH3Mod](https://github.com/Luisacaotica/ComfyUI-MiniMaxH3Mod), закреплённый на `517e8c419a8584fbf69fceb487bc39d83e6a6ec8` (v0.2.6), и небольшой пакет студии `custom nodes/minimax_studio_refmods`. Установщик не обновляет ComfyUI ради RefMods.

## Как пользоваться

1. Откройте **RefMods → Создать RefMod**. Добавьте файлы, текущие референсы либо материалы галереи. Каждый исходник станет независимым компонентом с собственной пропорцией. Звук видео можно сохранить отдельным компонентом.
2. Настройте обрезку изображения, диапазон видео/аудио и маску. Белое в маске сохраняет выбранную область. Для видео маска статическая на весь выбранный фрагмент.
3. Сохраните проект. **Full Reference** сохраняет закодированный референс; **Compressed Reference** позволяет уменьшить сетку и доработать латент. Сборка создаёт новую версию файла. Старые версии не перезаписываются.
4. В библиотеке выберите комплект и добавьте его в нужный раздел. Наборы Генерации, Продления, ControlNet, Refine, Face Refine и Tile Upscale независимы. Их можно сохранять как пресеты.
5. В блоке **Используемые RefMods** задайте компоненты, порядок, силу и количество копий. Копии расходуют дополнительные токены. **Настройки из файла** применяются отдельной кнопкой и появляются в полях кривых.
6. Для Генерации доступно **A/B**: две задачи с одними исходными параметрами и seed, без RefMods и с активным набором. Пары доступны в разделе **Сравнение**.

Предпросмотр декодирует сохранённое содержимое. Он не показывает качество переноса в новый ролик. Особенно это касается сильно сжатых файлов. Кривая кадров относится к кадрам исходного референса, кривая шагов — к вычислению каждого прохода. Это не расписание событий итогового ролика. Для одиночного изображения направление кривой кадров не имеет временного смысла; пакет использует её значение как ограничение силы.

Начальные бюджеты создания и применения — **5120 токенов RefMods**. Превышение вызывает ошибку; автоматического усечения нет. Стоимость обычных референсов показана отдельно как оценка; фактическая стоимость сохраняется после подготовки conditioning. Якорные кадры и текст не входят в эту оценку.

Refine, Face Refine и Tile Upscale используют визуальные компоненты, сохраняя исходный звук. Аудиокомпоненты в них неактивны. Выбор и отслеживание лица остаются настройками Face Refine. FPS и DLSS работают с готовыми роликами и не подключают H3-conditioning.

## Форматы и хранение

- Библиотека: `ComfyUI/models/refmods`, зарегистрированные внешние папки категории `RefMods`, `models/audio_refmods`, старый каталог `ComfyUI-MiniMaxH3Mod/mods`.
- Проекты и журналы: `data/refmods/projects` и `data/refmods/jobs`. Исходники копируются в проект. Данные пользователя не входят в Git.
- Версии сборок: `models/refmods/studio/<project-id>/...`. Предпросмотры: `ComfyUI/output/refmods/previews`.
- Старые самостоятельные RefMods и v5-комплекты читаются по содержимому заголовка safetensors. Проверяются типы, размеры, геометрия, метаданные и диапазоны тензоров. ReFLora/LoRA отклоняются. Библиотека не загружает тензоры на GPU.
- Импорт принимает файл или папку с файлами; отдельная загрузка ограничена 512 МБ. Для больших исходников используйте материалы галереи/текущие референсы. Экспорт выбранных компонентов копирует байты латентов в новый v5-комплект.
- Задача сохраняет настройки, версии, бюджет и полученную карту меток. Версия вычисляется по содержимому safetensors и сопутствующего JSON, если он есть. Изменившийся или отсутствующий файл требует явного обновления выбора перед повтором.

Метки обычных референсов создаются первыми, затем — активных компонентов RefMods. Отключённые компоненты и нулевая сила меток не занимают. Имя файла не становится триггерным словом. При перестановке привязки промпта сохраняются по идентификаторам. Пустой набор оставляет существующий граф без изменений.

Создание и предпросмотр стоят в общей очереди. Журнал с предварительно назначенным ID предотвращает повторную отправку после потери ответа. Перезагрузка страницы восстанавливает опрос; потерянная при перезапуске ComfyUI задача получает явную ошибку и не перезапускается сама.

## API и проверка

- `/api/refmods`: библиотека, импорт, проверка, обложки и экспорт; `?members=0,2` ограничивает экспорт компонентами.
- `/api/refmods/projects`: создание, сохранение и исходники. Сохранение проверяет `updatedAt`, чтобы открытая в другой вкладке версия не затёрла изменения.
- `/api/refmods/jobs`: сборка/предпросмотр, состояние, отмена по ID журнала.
- `/api/refmods/references`: оценка обычных референсов и наличие звука в видео, без GPU.

Проверки исходников: `node scripts/test-refmods.cjs`, `node scripts/test-refmods-jobs.cjs`. Проверка реального API нод: `ComfyUI-Easy-Install/python_embeded/python.exe scripts/test-refmods-python.py` (CPU). Браузерная проверка: `scripts/test-refmods-browser.cjs`; задайте `PLAYWRIGHT_PATH`, при необходимости `CHROME_PATH` и `STUDIO_TEST_URL` (по умолчанию порт 3001). Она создаёт тестовый проект и не запускает генерацию. Проверенные результаты GPU и ограничения оценки качества описаны в [отчёте](REFMODS_VALIDATION.md).

Аудио экспериментальное: [автор сообщает о неудачных проверках переноса личности голоса](https://github.com/Luisacaotica/ComfyUI-MiniMaxH3Mod#voice-transfer-limitations). Смешанный комплект не гарантирует привязку голоса к персонажу. Коллекция [malcolmrey/minimaxh3](https://huggingface.co/malcolmrey/minimaxh3/tree/main) содержит как RefMods, так и ReFLoras; расширение файла само по себе их не различает.
